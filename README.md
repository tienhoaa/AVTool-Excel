# AVTool Pro 2026 - Bộ Công Cụ Excel Chuyên Nghiệp

Bộ tiện ích mở rộng (Add-in) dành cho Microsoft Excel:
- **Đổi Font Tiếng Việt chuẩn**: TCVN3 (ABC), VNI sang Unicode, bảo toàn 100% công thức tính toán và giữ nguyên toàn bộ hình ảnh / shapes / biểu đồ.
- **Tính toán khối lượng dự toán (DValue)**: Tự động trích xuất và tính giá trị số từ chuỗi chữ diễn giải kích thước xây dựng, hỗ trợ đầy đủ các loại ngoặc `()`, `[]`, `{}` và tự động hiện hộp thoại Save As.
- **Tự động cập nhật Online**: Nhận thông báo và nâng cấp phiên bản mới nhất chỉ với 1 click chuột!

## Cài đặt nhanh (1 giây):
1. Tải về và giải nén file `AVTool_Pro_2026.zip`
2. Nhấp đúp chuột vào file `Cai_Dat_AVTool.bat`
3. Mở Excel lên là tab `AVTool` đã có sẵn trên thanh Ribbon vĩnh viễn!
